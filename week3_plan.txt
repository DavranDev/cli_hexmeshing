T1. TRUE HEADLESS MODE — IMPLEMENT `--headless`   (the centerpiece, 2-3 days)
--------------------------------------------------------------------------------
GOAL: a real `--headless` flag where NO GUI window/surface/swapchain is created —
the tool takes the input, runs the pipeline, writes output, exits. This is the
Week-2 HEADLESS.md "design B" (surfaceless Vulkan), promoted from memo to code.
Today's `--exit-after` opens the window then closes it; headless never opens it.

WHAT WE ALREADY KNOW (from W2 HEADLESS.md, cite in the upgraded memo):
  - main.cpp: `app.Prepare()` (main.cpp:28) runs BEFORE the script branch; that is
    where vkoo::Application::Prepare() builds glfwInit/window, VkInstance,
    VkSurfaceKHR, device, swapchain, render pipelines, Gui.
  - Compute is libtorch/CUDA, INDEPENDENT of the vkoo Vulkan device.
  - Every script-path view call is class (a) display-only EXCEPT the already-fixed
    Stage-1 polycube writeback; Discretization's pending_view_ block is class (c)
    mouse-only (never runs headless). So headless is a STARTUP GUARD, not a logic
    rewrite — the risky (b)-class side effect was already fixed in W1.
  - xvfb-run already passes the X11 half here; only the GPU/ICD is missing locally.

DESIGN DECISIONS (made up front):
  - Add `--headless` as a THIRD flag alongside --script/--exit-after (additive in
    main.cpp's existing arg loop, lines 14-21; update the usage string too).
  - Two-level guarding, decide level via 1.1's trace:
      LEVEL 1 (preferred, "design B"): keep VkInstance + logical device (in case
        any model/geometry allocates GPU buffers through the vkoo device at load),
        but SKIP glfwInit/window, VkSurfaceKHR, swapchain, render pipelines, Gui.
        A surfaceless instance needs no VK_KHR_surface/glfw and no X11 at all.
      LEVEL 2 (only if 1.1 proves the vkoo device is unused by compute): skip the
        Vulkan device entirely too — closest to "design A", biggest win, but only
        if nothing outside rendering touches the device.
  - Guard, don't delete: wrap GUI-creation in `if (!headless)` so the default GUI
    path is byte-for-byte unchanged. Same discipline as RunFromScript().
  - Success is METRIC-GATED: headless is only "done" when the smoke test still
    reports 0 inverted and metrics match the GUI run — that gate is [GPU-HOST].
